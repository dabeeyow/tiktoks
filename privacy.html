Privacy Policy

Last updated: 29 July 2026

Faceless Reels ("the Tool") is a personal tool that publishes short videos to its operator's own social media accounts. This policy explains what data it handles.

What the Tool stores

  • Access tokens. When you authorize the Tool with TikTok or YouTube, the resulting access and refresh tokens are stored locally on the operator's own server, in a file readable only by that server's user account. They are used solely to publish videos to the connected account.
  • Basic account identifiers. The Tool may read your account's display name, avatar, and posting permissions in order to confirm it is posting to the correct account.
  • Generated videos. Video files are created on the server and deleted immediately after a successful upload.

What the Tool does not do

  • It does not collect data from any account other than the operator's own.
  • It does not sell, rent, or share data with third parties.
  • It does not use TikTok data for advertising, profiling, or analytics.
  • It does not run a public service or store data for other users.

Third-party services

The Tool sends video files and post captions to TikTok and YouTube through their official APIs in order to publish them. It uses Pexels to retrieve stock background footage and the Anthropic API to generate the script text; neither receives your TikTok account data.

Data retention and deletion

Tokens are kept only while the Tool is in use. You can revoke the Tool's access at any time in your TikTok settings (Security & permissions → Manage app permissions), which immediately invalidates the stored token. Deleting the token file on the server removes it permanently. To request deletion of any data, contact the address below.
